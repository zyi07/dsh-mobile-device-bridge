# 移动设备

在 **设置 → 移动设备** 里连接 **安卓 / 鸿蒙** 手机，执行命令、截图、传文件、安装应用。支持**两条通道**：

- **浏览器（WebUSB）**：Chrome/Edge 直连 USB，无需装 SDK。
- **本机命令行（CLI）**：宿主自动探测 `adb`/`hdc` 并 spawn 调用；**桌面端首选**，绕开 WebUSB 权限与 WinUSB 驱动问题。

## 用法

1. 顶部选通道：「浏览器」或「本机命令行」。
2. **浏览器**：点「连接设备」→ 在弹窗里选手机（首次授权 USB）。
   **本机命令行**：点「刷新本机设备」→ 选中 adb/hdc 识别到的设备。
3. 下方输入命令 → 执行；或点截图。设备日志区可勾「完整日志（开发者）」看协议原始帧。

## 多设备

安卓 + 鸿蒙可同时连接，设备 chip 点击切换，命令默认发到当前活跃设备。鸿蒙还可扫码登录华为账号，自动申请调试证书/Profile 并签名 HAP 侧载。

## 前提与限制

- **WebUSB**：仅 Chromium 内核；需 HTTPS 或 localhost（DSH 默认 `http://127.0.0.1:3080` 满足）；Windows 上设备需绑定 **WinUSB** 驱动（安卓通常自带，鸿蒙常见需 Zadig）；标签页须在前台，后台会被浏览器节流断轮询。
- **本机 CLI**：本机需有可执行的 `adb` / `hdc`（PATH 或常见安装位）。鸿蒙设备在 WebUSB 选择器里固件自报名为 `HDC Device`（固件决定，无法改），连接后插件显示真实型号。
- 华为设备首次 `pm install` 可能弹「风险提示→继续安装→输密码」，需在系统设置关闭安装验证或手动完成。
- 两台**同为鸿蒙（HDC）** 的设备未做真机验证；安卓 + 鸿蒙跨系统已验证。
